# TechWave

**[View Live Demo →](https://devbyabir.github.io/techwave/)**

A responsive podcast landing page about technology, productivity, and personal growth. Built as part of my frontend learning journey with semantic HTML and custom CSS.

## What I practiced

- Translating desktop and mobile visual references into a responsive website
- CSS Grid for a five-card feature layout and Flexbox for navigation and actions
- A keyboard-accessible mobile menu using native HTML details and summary
- Gradient styling, layered backgrounds, positioned badges, and CSS animation
- Responsive YouTube embeds, meaningful image descriptions, and reduced-motion support

## Explore the page

The page includes a waveform hero, podcast introduction, listener statistics, feature cards, featured videos, a host profile, and platform links.

## Run locally

Open `index.html` in your browser, or serve this folder with any static web server. No installation or build step is needed.

## Built with

HTML5 and CSS3. No JavaScript, frameworks, or CSS libraries.

## Project notes

TechWave is a frontend practice concept, not an operating podcast service. The host profile, listener statistics, episode titles, and episode durations are presentation content from the visual reference. Embedded TED talks are related learning resources, not recordings produced by TechWave. Subscription links lead to listening platforms; this site does not collect email addresses.

Visual assets are based on the supplied practice design; episode poster crops were prepared from that reference. No claim of original visual-design authorship is made.
